## 🧾 Sobre o projeto

O **Refund** é um projeto guiado desenvolvido para praticar conceitos de **HTML**, **CSS** e **JavaScript**.  
Ele simula um pequeno sistema de controle de despesas, permitindo adicionar informações e visualizar totais de forma dinâmica — ideal para estudar manipulação de DOM e boas práticas de organização de código.

---

## 🚀 Tecnologias utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**

---

## 🧠 Funcionalidades

✔️ Adicionar despesas  
✔️ Atualizar totais automaticamente  
✔️ Interface responsiva  
✔️ Manipulação dinâmica do DOM
